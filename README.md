## ✨ Features

- **Mobile First & Fully Responsive**: Tailored layout scaling seamlessly across mobile, tablet, and desktop screens with an intuitive slide-out mobile menu.
- **Glassmorphism & Cyberpunk Styling**: Modern dark UI featuring backdrop blur effects, neon gradient glows, and ambient light sources.
- **Interactive Terminal**: Simulated Unix terminal on the hero section featuring interactive JSON configuration output and typing effect.
- **Dynamic Skill Filtering**: Filter core technical skills by category (Languages, Frameworks, Cloud & DevOps, Databases & Queues).
- **Portfolio Showcase**: Interactive project cards with live metrics, detailed modal popups, and filter controls.
- **Career Timeline**: Work experience timeline highlighting engineering accomplishments and microservices metrics.
- **Interactive Contact Form & Utilities**: Integrated email copy clipboard trigger with custom toast notifications.

---

## 🛠️ Tech Stack

- **Markup & Layout:** HTML5
- **Styling & Utility Classes:** [Tailwind CSS (via CDN)](https://tailwindcss.com/)
- **Icons:** [Font Awesome 6.4](https://fontawesome.com/)
- **Typography:** Google Fonts (*Inter* & *Fira Code*)
- **Scripting:** Modern Vanilla JavaScript (ES6+)
